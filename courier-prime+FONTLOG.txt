  Courier Prime Font Information
  
  Courier Prime is a monospaced font designed specifically 
  for screenplays. It was designed by Alan Dague-Greene for 
  John August and released by Quote-Unquote Apps under the 
  SIL Open Font License (OFL). 
  
  
  ChangeLog

  26 Jul 2026 (Dylan Kinnett)
- Reorganized into three families: "Courier Prime", "Courier Prime Sans",
  "Courier Prime Code". Each holds all its weights under one typographic
  family name; the Code family no longer splits Medium into a second family.
- Renamed the Code family from "Courier Prime Code Nerd Font Mono" to the
  shorter "Courier Prime Code" (fits length-limited terminal/editor fields).
- Replaced the screenplay Regular/Bold/Italic/Bold Italic: the fontain.org
  re-cut was an old v1.203 with fewer glyphs, no OpenType features, and broken
  monospace/bold flags. Now quoteunquoteapps v3.018 (correct metadata, wider
  coverage, stronger hinting).
- Standardized every face via build/harmonize.py: unified line metrics
  (typo/hhea 1600/-700, USE_TYPO_METRICS on, 1.123 em), post.isFixedPitch and
  PANOSE set to monospaced, usWin sized to the real glyph bounds so Nerd icons
  are not clipped, gasp {65535:15}. Replaces the old build/postprocess.py.

  27 Jun 2026 (Dylan Kinnett)
- Assembled a personal master set; all families standardized to hinted TTF.
- Added Courier Prime Code Nerd Font Mono (derivative): Nerd Fonts 3.4.0
  icons, single-width "mono", 4 weights. Restored the vertical line metrics
  to Courier Prime's native values (the Nerd patch had inflated them), set
  gasp for clean GDI antialiasing, and named the family
  "Courier Prime Code Nerd Font Mono".

  4 Nov 2015 (Christoph Haag)
- created fontforge sources as base to work on GNU/Linux
- added FONTLOG to .sfdir
- Mastered Font from Fontforge SFDIR to 
  UFO,OTF,TTF,EOT,WOFF,SVG
  
  25 Jan 2013 (Alan Dague-Greene) v 1.203
- Initial release
